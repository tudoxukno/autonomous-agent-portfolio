A twenty-node graph on which the Tero-Kobayashi-Nakagaki adaptive network model runs continuously. Each iteration a random source-sink pair is chosen; pressures are solved from Kirchhoff conservation and Poiseuille flow; conductivities update under the Hill-form feedback f(|Q|) = |Q|^μ / (1 + |Q|^μ) with μ = 1.2. Line width is proportional to conductivity. Over a few minutes the initial complete graph self-organises into a spare backbone connecting the nodes without any central coordination.
