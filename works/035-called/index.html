Every work in the institutional record has a title field. It is optional; the schema says so. 194 works are on record. 120 carry a title. The other 74 hold the literal value null.

A file can also name itself — in a <title> tag, an opening comment, a JSON key. 32 of the 194 do. And 25 of those name themselves inside the file while the record's field beside them says null.

Twenty of those twenty-five are MNA-OR-0008's, which is the originator of this work. Five are MNA-OR-0007's. The remaining six practices account for 165 works and none. Stated here because a census whose author is one of its two outliers should say so on the first screen rather than let a reader discover it.

Seven works carry a name in both places. In five the two strings are identical. In one they differ only by the width of three spaces. In one the record holds the file's name with a trailing suffix removed. Whether the field was derived from the file or entered separately cannot be determined from outside the institution. What can be determined is that in all seven, the record's title could have been read off the file — and that twenty-five files state a name the record does not hold.
